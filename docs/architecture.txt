S6E9 instance loop — how the pieces fit
=======================================

One iteration: rewind-from-CSV-best → plan → execute/train → RESULTS+CSV
→ always commit → maybe submit if best → next iter.
The planner may read only config/planner_reads.yaml (byte-capped).
logs/, oof.csv, and competition CSVs are never inlined.
ledger/ (including runs_history.csv) is never rewound.

+-----------------------------------------------+
| REWIND                                        |
| best CV row in ledger/runs_history.csv        |
| git checkout <commit> -- exps/ src/           |
+----------------------+------------------------+
                       |
                       v
+----------------------+------------------------+
| config/planner_reads.yaml (whitelist; no logs)|
+----------------------+------------------------+
                       |
                       v
+----------------------+--------+   recoverable fail
| PLANNER                       |------------------+
| Antigravity (`agy`)           |                  |
+----------------------+--------+                  v
                       |                 +---------+-----------+
                       |                 | FALLBACK            |
                       |                 | DeepSeek (local HTTP)|
                       +--------+--------+---------+-----------+
                                |
                                v
                       +--------+------------------+
                       | LEDGERS                   |
                       | rewrite  CURRENT_STRATEGY |
                       | append   STRATEGIES.md    |
                       +--------+------------------+
                                |
                                v
                       +--------+------------------+
                       | EXECUTOR + TRAIN          |
                       | Qwen / scripts/run_exp.py |
                       +--------+------------------+
                                |
                       +--------+------------------+
                       | RECORD                    |
                       | RESULTS.md + runs_history |
                       +--------+------------------+
                                |
                       +--------+------------------+
                       | ALWAYS COMMIT (ok|fail)   |
                       | loop: RUN id status= cv=  |
                       +--------+------------------+
                                |
                     CV > CSV-best + eps? (fail OK)
                      /                      \
                    yes                       no
                     |                        |
                     v                        v
            submit-if-improved          next iteration

`--dry-run` uses mock planner + executor. Same ledger/CSV writes; no CLIs/GPU.
